## PONTOS FORTES PARA O NÍVEL PLENO

- SDD (Specification Driven Development) — conhecimento sólido e aplicado
- Comunicação técnica — guia completo e prática no dia a dia
- Documentação de requisitos — specs detalhados com INVEST, MoSCoW, DDR
- Análise de viabilidade — framework de 30 perguntas muito bem estruturado
- Experiência real em projeto full-stack (Vue + C# + PostgreSQL no estágio, React Native + Firebase nos projetos pessoais)
- SPIKE — conceito aplicado no trabalho
