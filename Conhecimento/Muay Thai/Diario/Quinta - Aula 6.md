- Passada

## Técnica

### 3 min - Sequência 1
- Jab + direto, balança, jab + direto + passada chuta

### 3 min - Sequência 2
- Jab + direto, balança, jab + direto + passada + jab + passada chuta

### 3 min - Sequência 3
- Jab + direto, balança, jab + direto + passada + passada, jab + passada joelho
